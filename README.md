# App Móviles — Repositorio de prácticas

Repositorio con las prácticas de la unidad de aprendizaje **Desarrollo de Aplicaciones Móviles Nativas** (ESCOM-IPN).

## Estructura

Cada práctica está en su propia carpeta `AppMoviles_PracticaX/`:

- `AppMoviles_Practica1/` — Práctica 1: Instalación y Funcionamiento de los Entornos Móviles. Tres versiones de "Hola Mundo": Views/XML, Jetpack Compose y Flutter.
- `AppMoviles_Practica2/` y siguientes — se agregan conforme avanza el curso.

Dentro de cada carpeta hay un `README.md` con la descripción, las instrucciones de ejecución y las evidencias de esa práctica.

## Cómo ver una práctica

En el navegador: `https://github.com/TheMike54/appsmoviles/tree/main/AppMoviles_Practica1`
