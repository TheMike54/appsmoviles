# Notas — MCP (Model Context Protocol)

MCP es un protocolo abierto basado en JSON-RPC 2.0. Un servidor MCP publica un catálogo
de herramientas (tools), recursos (resources) y plantillas de prompt (prompts) que un
cliente puede descubrir en tiempo de ejecución.

El servidor de sistema de archivos es uno de los servidores de referencia del protocolo,
no una parte de la especificación en sí.
